# 🚗 Car Finder App

A beautiful car listing app built with React (Next.js) and TailwindCSS.

## 🌟 Features

- Dark/Light Mode Toggle
- Live Filtering: Brand, Fuel Type, Price Range
- Sorting by Price (Low to High / High to Low)
- Wishlist stored in LocalStorage
- Beautiful UI with animations

## 🚀 Live Demo

👉 [https://car-finder-app.vercel.app](https://car-finder-app.vercel.app)

## 🛠️ Setup Instructions

1. Clone this repo:
git clone https://github.com/YOUR_USERNAME/car-finder-app.git

2. Install dependencies:
npm install

3. Run the app:
npm run dev


4. Visit `http://localhost:3000`
